# IPL Final Score Prediction (Multiple Linear Regression)

This project predicts the final innings score in IPL matches using a simple Multiple Linear Regression model.

## Problem Statement
Predict the final team score using mid-innings match context:
- Score after 10 overs  
- Wickets Left  

## Dataset
Ball-by-ball IPL data was processed separately to create a clean modeling dataset.
This folder contains only the extracted features used for training.

## Model
- Algorithm: Multiple Linear Regression  
- Metric: R² ≈ 0.62  

## Files
- `Multiple_LR.ipynb` – Notebook for training and evaluation  
- `dataset.csv` – Extracted features for modeling  

## Notes
Feature engineering was done in separate scripts/notebooks.
This notebook focuses on modeling and evaluation only.
